# 云澜 PMS · 酒店管理系统

面向酒店内部员工的单店 PMS（Property Management System），零构建、零外部依赖的原生 HTML/CSS/JS 完整前端项目，数据通过 Mock API + localStorage 持久化。

## 演示账号（密码均为 `123456`）

| 账号 | 姓名 | 角色 | 可见模块 |
|---|---|---|---|
| `manager` | 店长 | 全部模块 + 全部操作 |
| `front` | 前台 | 总览/房态/预订/接待/客档/客房/账务（可收款，不可作废） |
| `housekeeping` | 客房部 | 房态看板、客房管理（清洁/维修任务） |
| `finance` | 财务 | 总览/账务/报表/客档（可作废账目、开票） |
| `admin` | 系统管理员 | 系统设置 + 全局只读 |

## 核心功能模块

| 模块 | 功能 |
|---|---|
| 经营总览 | 出租率/预抵/离店/营收统计卡、今日预抵待办、房态速览、预警提醒、14 天出租率趋势 |
| 房态看板 | 按楼层的房态芯片矩阵（空净/空脏/在住/预抵/停用）、7 日房态条带、房间详情抽屉、快捷入住/退房/停用 |
| 预订管理 | 筛选搜索、新建/修改预订（含满房与日期校验、自动报价）、排房、取消、详情 |
| 前台接待 | 今日预抵（含超时未到红色预警）、办理入住（选房/押金/支付方式）、在住名单、退房结账（账单明细、多退少补、自动派清洁任务） |
| 客人档案 | 客人列表、会员等级/标签/偏好备注、住宿历史、自动建档 |
| 客房管理 | 清洁/维修任务三列看板（待处理/进行中/已完成）、任务分派、完成清洁自动恢复可售 |
| 账务中心 | 账单列表与明细、杂项入账（常用项目快捷）、收款、作废（财务权限）、发票标记 |
| 经营报表 | 出租率趋势折线、营收柱状图（手写 SVG）、渠道构成、房型出租分析、ADR/RevPAR |
| 系统设置 | 员工增删改停用、角色分配、房型价格调整、数据导出 JSON、一键重置演示数据 |

## 技术架构

```
hotel-pms/
├── index.html              入口
├── css/
│   ├── tokens.css          设计 Token
│   ├── base.css            布局骨架 / 导航 / 排版 / 响应式
│   └── components.css      按钮/表格/模态/抽屉/房态芯片/图表
├── js/
│   ├── utils.js            DOM/日期/金额/校验工具
│   ├── mock/seed.js        演示数据种子
│   ├── store.js            localStorage 持久化仓库
│   ├── mock/api.js         Mock API 层（模拟延迟 + 业务规则 + 校验）
│   ├── auth.js             会话 + RBAC 权限矩阵（5 角色 × 页面/动作双层）
│   ├── components.js       模态/抽屉/确认框/Toast/表格组件
│   ├── router.js           哈希路由 + 登录守卫 + 权限守卫
│   ├── pages/              9 个业务页面（login/dashboard/rooms/bookings/…）
│   └── main.js             启动引导
├── e2e-test.js             端到端业务流测试（Node，28 条断言）
└── README.md

## 运行测试

```bash
cd hotel-pms && node e2e-test.js
# 覆盖：种子校验 / 创建预订 / 满房与日期校验 / 排房→入住→加项→退房结账 /
# 重复退房拦截 / 清洁任务联动 / 停用拦截 / 账目作废 —— 28 条断言
```

## 已知边界

- 无真实后端：密码明文存储于 Mock 数据，登录仅供演示角色切换。
- 报表的 14 天趋势为种子历史数据；实时数据（订单/账务）为全量实时计算。
- 团队订单、夜审、多币种等企业级深度功能未展开，模块结构已预留扩展位。
